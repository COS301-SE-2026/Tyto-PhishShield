# COS301 Capstone Research

This folder contains early research for the Tyto PhishShield capstone project.  

## Research topics

| Topic | Summary | File |
|---|---|---|
| Architecture style | Compares microservices, modular monoliths, and Docker-based deployment options for a small team. | [architecture-style.md](./architecture-style.md) |
| Office.js API & Outlook add-in lifecycle | Explains how the Outlook “Report Phish” button can be added using Office.js and an add-in manifest. | [officejs-outlook-addin.md](./officejs-outlook-addin.md) |
| LLM fallback & LangChain orchestration | Researches how to structure AI generation so OpenAI and local Llama fallback models can be swapped. | [llm-fallback-langchain.md](./llm-fallback-langchain.md) |
| Real-time gamification & WebSocket architecture | Covers Socket.IO, NestJS WebSocket gateways, Redis Pub/Sub, and live leaderboard updates. | [realtime-gamification-websockets.md](./realtime-gamification-websockets.md) |
| Auth0 vs Firebase for RBAC and Outlook SSO | Compares authentication options for role-based access control and Outlook add-in login flow. | [auth0-vs-firebase-rbac.md](./auth0-vs-firebase-rbac.md) |
| Email sending & spoofing simulation | Covers safe phishing simulation email delivery, headers, Mailu, SPF/DKIM/DMARC, and legal constraints. | [email-sending-spoofing.md](./email-sending-spoofing.md) |
| Data anonymisation & POPIA/GDPR compliance | Explains anonymisation, pseudonymisation, PII separation, RBAC access, regex sanitisation, and Microsoft Presidio. | [data-anonymisation-popia-gdpr.md](./data-anonymisation-popia-gdpr.md) |

| CI/CD & Dockerised Ubuntu deployment | Researches GitHub Actions, Docker Compose, Ubuntu deployment, reverse proxy setup, and monitoring. | [cicd-docker-ubuntu.md](./cicd-docker-ubuntu.md) |
